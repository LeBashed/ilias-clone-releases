# ILIAS-Clone – Releases

Hier liegen nur die fertigen Installer der **ILIAS-Clone Desktop-App** (Windows).
Die App prüft dieses Repository selbst auf neue Versionen und aktualisiert sich automatisch
(einstellbar unter *Einstellungen → Updates*).

**Installieren:** unter *Releases* die neueste `ILIAS-Clone Setup x.y.z.exe` herunterladen und ausführen.
Die App ist nicht signiert – Windows zeigt beim ersten Start „Weitere Informationen → Trotzdem ausführen“.

Der Quellcode ist privat.
